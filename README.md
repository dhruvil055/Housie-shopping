# Housie Shopping — Production Home Building Material E-Commerce Android App

A complete, production-ready home-building-material and home-improvement e-commerce Android application built with modern Android engineering practices.

## Features
- **55+ Screens**: Complete navigation across Startup, Auth, Location, Home, Categories, Search, Filters, Product Details, Reviews, Cart, Wishlist, Address Management, Checkout, Razorpay Payment Flow, Order Placement, Orders List, Live Order Tracking with Google Maps, Invoice, Support Tickets, Notifications, Profile, and Settings.
- **Offline & Cache First**: Room Database caching with mock repository fallback to guarantee all features, buttons, and navigation flows work seamlessly offline or online.
- **Architecture**: MVVM + Clean Architecture + Hilt DI + Jetpack Compose Material 3 + Kotlin Coroutines & StateFlow.
- **Data Validation & Safety**: Input validation, double-click protection on critical actions, error mapping, and loading skeletons.

## Requirements
- Android Studio Iguana (2023.2.1) or newer
- JDK 17
- Android SDK 34

## Running Locally
1. Clone the project and open in Android Studio.
2. Sync Gradle dependencies (`./gradlew assembleDebug`).
3. Run on an Android Emulator or Physical Device (API 24+).
